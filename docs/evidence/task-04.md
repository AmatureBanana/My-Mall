## 交付内容

- `GET /api/account/profile` 只返回Session对应的ID、用户名、昵称和角色；查询参数不能切换所有者。
- `POST /api/account/profile` 只接受昵称，最多30个Unicode码点；缺失字段、类型错误、保护字段和未配对代理字符均拒绝。空昵称沿用注册的用户名回退规则，长度校验先于空白回退。
- `POST /api/account/password` 验证旧密码、新密码及确认值；新密码复用8～64字符、UTF-8最多72字节约束，使用受管BCrypt。
- V8新增默认0的凭据版本；账户行锁下校验Session版本，事务内更新哈希并递增版本，成功后结束当前Session。全部其他旧Session在下一次请求的安全过滤阶段被拒绝；并发旧凭据不能覆盖新密码。登录主体继承Spring Security User，保留认证后擦除密码行为。
- Vue个人资料与账户安全弹窗提供只读身份、昵称保存、改密与错误反馈；成功后转登录，清空密码字段；关闭后忽略晚到响应。管理员沿用相同的本人账户入口。
