# 普通用户管理

管理员从统一登录进入“管理后台 → 用户管理”，或打开 `/#admin/users`。列表支持用户名与账户状态组合筛选、分页、普通用户详情；详情只允许启用或禁用，操作前显示用户名及确认提示。页面复用已有后台导航、表格、分页、反馈样式及 Session/CSRF 请求层。

## HTTP 契约

全部接口要求有效 ADMIN Session。匿名请求返回401，普通 USER 返回403；写请求还需要通过 `/api/auth/csrf` 获取的 CSRF 凭证。身份及审计操作者取自服务端 Session。

| 请求 | 作用 |
| --- | --- |
| `GET /api/admin/users?username=&status=&page=1&size=10` | 只查询 USER；用户名首尾空白忽略、不区分大小写、按字面子串匹配，最长20字符；状态可省略，或为 ACTIVE / DISABLED；page≥1，size为1～100 |
| `GET /api/admin/users/{id}` | 普通用户必要详情；不存在或目标为 ADMIN 时404 |
| `POST /api/admin/users/{id}/status` | 仅接受 `{"status":"DISABLED","revision":0}` 或 ACTIVE；版本必须为非负JSON整数 |
| `GET /api/admin/users/{id}/audit` | 核验该普通用户最近100条共享审计，按ID倒序；不新增专用审计页面 |

统一响应为 `{"data": ...}`。列表包含 `items/total/page/size`；详情包含 `id/username/nickname/role/status/revision/createdAt/updatedAt`。SQL直接投影安全字段，响应和审计均不包含密码、密码哈希、凭据版本及会话凭证。管理员不出现在普通用户列表或详情中。

用户不存在为404/`USER_NOT_FOUND`，试图通过状态入口修改任意管理员为403/`ADMIN_PROTECTED`；旧版本为409/`USER_CONFLICT`，必须重新载入再操作。非法查询、ID、状态、版本及额外写入字段为400/`INVALID_INPUT`。数据库或审计写入不可用为503/`AUTH_UNAVAILABLE`，不转换为空结果或成功提示。

状态入口不接受用户名、昵称、角色、密码、用户标识、删除标记等字段，也不提供通用资料编辑、改角色、重置密码或物理删除能力。所有管理员均不可经此入口启禁，因此最后有效管理员同样受保护。

## 事务、会话和历史

V11新增独立的 `account.administration_revision` 及普通用户状态查询索引，不修改既有迁移。状态修改先锁定账户行，检查 USER 角色与状态版本。实际状态变化时只更新状态、状态编辑版本及私有凭据版本，并通过任务05的 `AdministrationAudit` 在同一事务记录操作者、USER对象、时间、STATUS动作和安全的前后值；审计失败时全部回滚。

同一版本并发修改只有一个成功。相同状态、相同版本的重复请求返回当前详情，不增加版本或重复审计；已发生变化后的旧版本重试返回409。资料和密码修改继续使用现有账户服务，不开放新的旁路。

禁用后的新登录被现有认证机制拒绝。每次既有会话请求均由现有 `AccountSessionFilter` 检查当前账户状态及凭据版本；下一个受保护请求返回401，包括携带旧CSRF的写请求。状态变化同时增加凭据版本，因此禁用期间没有发出请求的旧会话，在重新启用后也不能恢复权限，必须重新登录。禁用不追溯撤回已经通过校验、正在执行的请求；后续交易服务仍须在自身事务内复核账户和业务条件。

该入口仅更新账户行，保持ID、用户名、密码、昵称及既有业务关联。购物车、订单和已支付订单没有删除、取消或变更操作；这些模块尚未交付，其历史保留的完整场景由对应后续任务联合验证。

## 验证

`UserAdministrationTest` 通过真实隔离 MySQL 和公开HTTP验证查询、字段暴露、启禁、既有及休眠会话、保护字段、管理员保护、401/403/CSRF、审计故障回滚及同步并发。SQL只用于夹具、故障注入和清理，业务结果通过HTTP观察。

`frontend/tests/user-administration.spec.ts` 以独立浏览器context验证管理员、普通用户和被禁用用户，并覆盖确认/取消、筛选、失败重试、空结果和真实并发冲突。浏览器中的503网络注入只验证页面反馈，真实审计回滚由后端MySQL故障注入证明。执行记录见[任务06验证](evidence/task-06.md)。无新增依赖、外部代码或数据复制。
