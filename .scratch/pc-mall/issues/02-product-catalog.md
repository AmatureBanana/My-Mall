## Acceptance criteria

- [x] 游客可访问八类硬件列表，按类别及基础关键词查询；空结果与请求失败可区分。
- [x] 商品详情展示名称、品牌、型号、描述、图片地址、当前售价、库存和必要分类参数。
- [x] 实际商品 ID、类别与销售 SKU 一致；内存套装容量与条数分别展示，集合参数及单位明确。
- [x] 下架商品不出现在新选配候选中；对不存在或不可选商品返回明确结果。
- [x] 查询读取当前数据库数据，为后续 DIY 复用同一商品来源。
- [x] 用接口及浏览器测试覆盖分类、搜索、详情、空结果和无效商品 ID。
