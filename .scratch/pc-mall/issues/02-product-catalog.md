# 02: 商城分类、搜索与商品详情

**What to build:** 游客浏览八类硬件、搜索并查看当前价格、库存和必要参数。

**规格依据：** [电脑智能选配与商城联动系统实施规格](../spec.md)，版本 1.0，2026-10-28；原报告、追踪矩阵及来源指纹见母规格。保留原需求基线，本票不改冻结规则或增加 P1/P2 范围。

**范围与交接：** 总体 G-01、公共商品能力；F02-03/05 的基础依赖。

公共查询独立于管理员操作。展示字段覆盖后续十项规则所需逻辑参数，类别不扩展到整机或外设；候选资料需逐字段核验。

## Acceptance criteria

- [ ] 游客可访问八类硬件列表，按类别及基础关键词查询；空结果与请求失败可区分。
- [ ] 商品详情展示名称、品牌、型号、描述、图片地址、当前售价、库存和必要分类参数。
- [ ] 实际商品 ID、类别与销售 SKU 一致；内存套装容量与条数分别展示，集合参数及单位明确。
- [ ] 下架商品不出现在新选配候选中；对不存在或不可选商品返回明确结果。
- [ ] 查询读取当前数据库数据，为后续 DIY 复用同一商品来源。
- [ ] 用接口及浏览器测试覆盖分类、搜索、详情、空结果和无效商品 ID。
