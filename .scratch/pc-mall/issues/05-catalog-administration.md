## Acceptance criteria

- [x] ADMIN 可分页筛选商品并查看详情，普通用户直接调用管理接口被拒绝。
- [x] 新增八类商品默认 OFF_SALE，SKU 与商品 ID 唯一；SKU 和类别创建后不可变。
- [x] 可维护名称、品牌、型号、描述、图片地址及八类专属参数，校验类型、集合语义和单位。
- [x] 参数模型覆盖 F03 C01～C10 的完整所需字段，不以候选数据集缺字段缩减基线。
- [x] 缺必要信息或适用参数时拒绝上架并指出原因；上下架不物理删除商品及历史关联。
- [x] 关键参数及上下架变更记录操作者、对象、时间与变更内容，需要原子的变更与审计一起提交。
- [x] 用管理页面、真实 MySQL 接口及错误注入验证新增、重复 SKU、编辑、上架拒绝和审计回滚。
