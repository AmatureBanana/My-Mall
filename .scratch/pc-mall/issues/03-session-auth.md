## Acceptance criteria

- [x] 注册校验用户名大小写唯一、确认密码及字段限制，仅创建 USER，成功后进入登录而非自动登录。
- [x] 密码为 8～64 字符且 UTF-8 不超过 72 字节，使用 BCrypt，不存储或返回明文密码。
- [x] USER/ADMIN 共用入口，通过服务端 Session 登录和退出；空闲两小时过期，身份不取自客户端 user_id。
- [x] 公开商品可匿名访问；受保护请求未认证返回 401，普通用户访问管理能力返回 403。
- [x] 浏览器写请求使用 CSRF，退出后旧会话不可用；Cookie 属性与本机同源环境匹配。
- [x] 管理员由安全初始化机制创建，凭据不入仓库；提供后台导航基础与明确权限反馈。
- [x] 错误凭证、异常输入与可配置限流有测试；浏览器和接口验证注册、登录、退出及越权。
