# 16: 单品原子下单与成交快照

**What to build:** 从已选单品确认现价后事务下单，预占库存、写快照并清理选中项，失败整体回滚。

Blocked by: [07：价格与可售库存受控调整](07-price-stock.md)，[13：单品购物车持久化与数量管理](13-single-item-cart.md)

**规格依据：** [电脑智能选配与商城联动系统实施规格](../spec.md)，版本 1.0，2026-10-28；原报告、追踪矩阵及来源指纹见母规格。保留原需求基线，本票不改冻结规则或增加 P1/P2 范围。

**主责需求：** F06-01、F06-02、F06-05、F06-06、F06-07、F06-11、F06-12、F06-13、F06-14、F06-15、F06-16、F06-17

**范围与交接：** 从本人已选单品到原子订单、预占和不可变快照。

先验证单品完整路径；整机混合下单由17补齐，未实现时明确拒绝而非按普通商品绕过兼容准入。所有权、幂等和事务保护不能留到最后补。

## Acceptance criteria

- [ ] 只能从本人服务端已选购物项创建订单，检查存在、归属、数量和当前内容版本，拒绝伪造明细。
- [ ] 最终读取当前可售状态、库存及现价；确认后再次变价仍需确认，金额按CNY精确计算。
- [ ] 幂等键绑定用户、操作与内容，同内容重试得到同笔订单，不同内容复用同键被拒绝。
- [ ] 在统一事务内预占库存、生成唯一订单号、写成交快照并仅清理选中项，任一步失败全部回滚。
- [ ] 成功为PENDING_PAYMENT，服务端截止时间为创建后30分钟；未选项保留。
- [ ] 并发有限库存不能超卖，后台调整与下单共用固定锁顺序和受控库存，不残留部分扣减。
- [ ] 以故障注入、重复并发提交和真实MySQL验证原子性；浏览器可创建并查看订单结果。
