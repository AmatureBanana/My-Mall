## Acceptance criteria

- [x] 锁定兼容正式依赖，前后端开发启动和同源演示构建均可复现。
- [x] MySQL 演示库与测试库显式分开；配置缺失或误指演示库时测试安全拒绝，不回退到内存库。
- [x] 版本化迁移可从空库建立最小商品数据，重复启动不重复导入；样本含真实型号、来源及演示价说明。
- [x] 游客通过真实后端接口在浏览器看到数据库商品的名称、类别、现价与库存，不使用静态假接口。
- [x] 数据库不可用或接口失败时显示明确错误，不伪装为空商品列表或成功。
- [x] 完成真实 MySQL 接口验证和一条浏览器展示验证，记录构建、迁移及启动方法。
