# 13: 单品购物车持久化与数量管理

**What to build:** 本人购物车支持单品加购、同SKU合并、数量调整和删除，退出重登后保留。

Blocked by: [02：商城分类、搜索与商品详情](02-product-catalog.md)，[03：注册登录、会话与后台准入](03-session-auth.md)

Status: ready-for-agent

**规格依据：** [电脑智能选配与商城联动系统实施规格](../spec.md)，版本 1.0，2026-10-28；原报告、追踪矩阵及来源指纹见母规格。保留原需求基线，本票不改冻结规则或增加 P1/P2 范围。

**主责需求：** F05-01、F05-02、F05-03、F05-04、F05-05、F05-06

**范围与交接：** 本人持久化单品购物车首个完整购买入口。

本票先完成单品，不将未实现的配置组当作普通商品接收。读取与写入不预占库存，后续配置组复用同一逻辑购物车。

## Acceptance criteria

- [ ] 仅登录用户可操作本人购物车，服务端取身份并校验资源归属，不能伪造user_id越权。
- [ ] 合法在售有库存的真实SKU可入车，同SKU普通单品合并，数量为1～99且受可售数量限制。
- [ ] 可查看、修改数量与删除单品，金额由服务端现价计算，非法修改保持原记录。
- [ ] 购物车持久化，退出重登后仍存在；查询和增删改都不预占或扣减库存。
- [ ] 重复请求和并发增加不会意外重复加购或丢数量，错误有明确页面反馈。
- [ ] 真实MySQL和浏览器验证合并、0/100/超库存边界、数据恢复、越权与并发修改。
