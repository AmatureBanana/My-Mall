# 12: 游客登录恢复与权威重验

Blocked by: [03：注册登录、会话与后台准入](03-session-auth.md)，[11：图形输出、功率、空间与完整核心准入](11-compatibility-admission.md)

**规格依据：** [电脑智能选配与商城联动系统实施规格](../spec.md)，版本 1.0，2026-10-28；原报告、追踪矩阵及来源指纹见母规格。保留原需求基线，本票不改冻结规则或增加 P1/P2 范围。

## Acceptance criteria

- [ ] 游客选配后进入统一登录，成功后恢复原商品引用、来源和当前工作区，不绑定永久游客账户。
- [ ] 恢复重新读取当前商品、价格、库存及参数，并调用当前完整F03服务，不能沿用缓存通过结论。
- [ ] 商品下架、缺货、变价、参数变更或无效ID有明确诊断，尽量保留用户可调整的选择。
- [ ] 登录失败或取消不会自动加购、下单或错误清空配置；登录成功也不自动加购。
- [ ] 保护配置修订及异步响应，恢复期间的新编辑不被旧恢复结果覆盖。
- [ ] 浏览器验证正常恢复、登录失败及商品变化；接口测试确认恢复本身不创建购物车组。
