## Acceptance criteria

- [x] ADMIN 可按用户名、状态查询普通用户列表与必要详情，不暴露认证敏感字段。
- [x] 可将普通 USER 设为 ACTIVE/DISABLED，禁用后的登录及既有会话受保护请求均被拒绝。
- [x] 普通管理入口不能提升角色、改用户名或密码、删除账户、禁用管理员或破坏最后有效管理员。
- [x] 启用、禁用与必要审计一致提交，失败不留下半成功状态。
- [x] 状态变化保留购物及订单历史，不自动取消已支付订单。
- [x] 使用管理员、普通用户和已登录被禁用用户验证界面、接口授权及状态即时生效。
