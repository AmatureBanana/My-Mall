# 15: 配置组修改、失效诊断与混合预结算

**What to build:** 通过DIY整组替换，失败保留原组；展示变价和失效原因，按整组选择有效项目预结算。

Blocked by: [07：价格与可售库存受控调整](07-price-stock.md)，[14：合法配置整组入车与去重](14-configuration-cart.md)

Status: ready-for-agent

**规格依据：** [电脑智能选配与商城联动系统实施规格](../spec.md)，版本 1.0，2026-10-28；原报告、追踪矩阵及来源指纹见母规格。保留原需求基线，本票不改冻结规则或增加 P1/P2 范围。

**主责需求：** F05-14、F05-18、F05-19、F05-20、F05-21、F05-22、F05-24

**范围与交接：** 已有配置安全编辑、实时失效诊断与只读结算预检查。

报价确认不是锁价，预检查不是订单创建。本票复用07的当前价格库存和14的完整配置组，不将未选中的失效项变成全车阻断。

## Acceptance criteria

- [ ] 配置组返回DIY编辑，重新重验成功后原子替换原组；用户取消、冲突或失败时原组不变。
- [ ] 读取当前商品状态、参数、价格和库存，失效项保留并区分缺货、下架、不兼容及无法验证。
- [ ] 服务端计算单品、组与选中总额；变价明确提示并需确认，参考价不是成交价。
- [ ] 支持选中部分单品与完整组，拒绝组内部分选择；未选中无效项不阻断有效选择。
- [ ] 预检查按选中项汇总同SKU需求，返回服务端购物项与完整组关系供F06最终重验，不预占库存。
- [ ] 并发编辑或报价变化有冲突/重验反馈，不用过期内容静默替换或结算。
- [ ] 真实数据库及浏览器验证编辑回滚、混合选择、精确金额、失效保留和并发价格变化。
