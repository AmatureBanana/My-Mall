# 04: 个人资料、昵称与修改密码

**What to build:** 用户查看本人资料、修改昵称和密码；改密使相关旧会话失效。

Blocked by: [03：注册登录、会话与后台准入](03-session-auth.md)

Status: ready-for-agent

**规格依据：** [电脑智能选配与商城联动系统实施规格](../spec.md)，版本 1.0，2026-10-28；原报告、追踪矩阵及来源指纹见母规格。保留原需求基线，本票不改冻结规则或增加 P1/P2 范围。

**主责需求：** F01-07、F01-08、F01-09

**范围与交接：** 本人资料与账户安全。

不新增头像上传、手机号、邮箱、自助找回密码或管理员重置密码能力。

## Acceptance criteria

- [ ] 登录用户仅可查询本人 ID、用户名、昵称等必要资料，不返回密码哈希和会话凭据。
- [ ] 昵称可修改且最多 30 字符；用户名、ID、角色与账户状态不能经资料接口修改。
- [ ] 修改密码必须验证旧密码及新密码限制，错误输入保持原账户可用。
- [ ] 改密成功后新密码生效，相关旧会话全部失效并要求重新登录。
- [ ] 伪造其他用户标识、未登录请求和缺失 CSRF 的写请求不能修改资料。
- [ ] 以两个浏览器会话及真实数据库测试资料隔离、昵称边界和改密失效。
