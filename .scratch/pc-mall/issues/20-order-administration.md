## Acceptance criteria

- [ ] ADMIN 可按订单号、状态、用户等基本条件分页查询四类状态订单，普通用户不能访问。
- [ ] 可查看购买人、商品和配置分组、数量、成交金额及状态，商品后续修改不改变展示快照。
- [ ] 只能通过F06将PAID变为COMPLETED，记录完成时间、操作者与必要审计。
- [ ] 拒绝待支付直接完成、取消后恢复、已支付直接取消及任意改金额/明细/状态。
- [ ] 并发和重复完成最多产生一次有效转换及业务审计，不再次扣库存。
- [ ] 真实MySQL和管理页面覆盖基本筛选、越权、快照、合法完成、非法状态和审计回滚。
